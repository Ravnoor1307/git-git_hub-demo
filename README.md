# Git & GitHub

This repository contains my learning notes on Git and GitHub, including
essential Git commands, version control concepts, and practical examples.

## 📚 Topics Covered

- Introduction to Git and Version Control Systems (VCS)
- Centralized vs. Distributed Version Control
- Git Installation and Configuration
- Creating and Cloning Repositories
- Git Status, Add, and Commit
- Writing Good Commit Messages
- Using `.gitignore`
- Viewing Commit History and Changes
- Creating and Managing Tags
- Branching and Merging
- Working with Remote Repositories
- Fetch, Pull, and Push
- Uploading Projects to GitHub
- Undoing Changes and Troubleshooting

## 🎯 Purpose

The purpose of this repository is to learn Git and GitHub step by step
and maintain practical notes for future reference.
